# Hobbit-Book-Cover-Prompt-Generator

1. Copy and paste the card details into the card_input.txt file. Enter the card rarity in the Rarity field.

2. Run "python3 mtgPromptGenerator.py"

3. Your prompt will be within the "generated_prompts" folder under the name of the card uploaded.

4. Paste prompt into Gemini and uploaded the included Thranduil.jpg as a reference for Gemini.

5. Enjoy!
